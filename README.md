# @opinionated-ts/write-once-markdown

Official Markdown integration for [write-once](https://github.com/opinionated-ts/write-once).

This package is under development. Its public API and supported Markdown extraction behavior will be documented here as the integration is implemented.

## Development

```sh
bun install
bun test
bun check
bun build
```

## Related projects

- [write-once](https://github.com/opinionated-ts/write-once) — core resource preparation, resolution, and content extraction pipeline.
- [Opinionated TS](https://github.com/opinionated-ts) — the ecosystem this package belongs to.
